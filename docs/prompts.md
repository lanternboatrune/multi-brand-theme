# 头像与立绘提示词

本文件记录《多品牌外观》插件作者账号「灯舟_Rune」的形象提示词，分本地与平台两套。

## 0. 两套用在不同地方

| 用途 | 管线 | 关键词倾向 |
|---|---|---|
| 头像 | 任意 | 大色块、强轮廓、少细节，缩到 48 像素仍可辨认 |
| 立绘、宣传图 | 本地 ANIMA | 真实光影、更多细节、半厚涂 |

需要说明的是，追求细节和追求小尺寸可辨认是一对矛盾。头像不要堆细节，堆了缩小就糊成一团。

## 1. 本地 ANIMA 版

环境：`D:\Develop\AI Image`，ComfyUI 0.44.0 + ANIMA 1.0，RTX 3060 Laptop 6GB，必须 `--lowvram`。

### 1.1 提示词习惯

这个模型对「平涂」「日系二次元」这类词反应很直接，一出现就退回九十年代赛璐璐动画的大眼纯色块画风。要现代质感，必须明确要真实光影与细节。

### 1.2 正向

```text
Q版卡通角色，银白色头发的少女，发尾渐变青蓝色，青蓝色眼睛，表情安静，
双手捧着一盏半透明纸灯，灯罩透出暖橙色光，灯面有几道淡金色符文，
深青黑色夜晚背景，水面反光，柔和光晕，
真实光影，立体感强，细节丰富，精细的发丝与灯罩纹理，柔和体积光，
冷色轮廓光从下方打上来，画面只有银白、深青、暖橙三种主色，人物居中
```

### 1.3 负向

```text
日系二次元，平涂，赛璐璐，纯色块，九十年代动画，僵硬阴影，简单线条，
worst quality, low quality, blurry, jpeg artifacts, text, watermark, logo, extra fingers
```

### 1.4 参数

```text
分辨率   640×640 或 512×768
步数     30
CFG      4.0
采样器   euler / simple
denoise  1.0
```

单张墙钟约 24 至 30 秒，显存峰值 4.2 至 5.0 GB。

## 2. 平台版

平台：liblib，模型 Qwen-Image，另挂 LoRA「Qwen-Q版卡通人物角色」，强度 0.8。
出图成本 1 积分一张，对照 Seedream 5.0 Pro 的 14 积分一张。

### 2.1 正向

```text
Q版卡通人物角色，银白色头发的少女，发尾渐变青蓝色，青蓝色大眼睛，表情安静自然，
双手捧着一盏半透明的纸灯，灯罩透出暖橙色光，灯面有几道淡金色符文，
暖橙是画面唯一的暖色光源，深青黑色夜晚背景，水面柔和反光，
冷色轮廓光从下方打上来，人物居中，正方形构图，简洁背景
```

### 2.2 负向

```text
文字，水印，Logo，多余人物，杂乱背景，复杂场景，多余的手指
```

### 2.3 注意

1. LoRA 的参考缩略图来源需先确认，若本身就是他人角色，出图会带该角色特征，与「原创」要求冲突。
2. 一次跑四张同提示词，比较种子差异。
3. Qwen-Image 是基础模型，不支持锁定构图编辑，改一版等于重抽一次。

## 3. 圆裁检查

出图后做三件事再决定用哪张。

1. 缩到 200×200，看主体是否还认得出。
2. 正圆裁切，看头顶与下巴是否被切。
3. 缩到 48×48，看暖橙光源是否还在。

三关都过的才是可用的头像。
