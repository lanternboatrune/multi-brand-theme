## 一、标题候选

按「一遍读得懂 + 有数字 + 有断言」排。

1. **我把 DSH 换成了 Claude 的样子，只用了一个插件**
   主推。有反差、有对象、有结果，读完知道点进去能看到什么，不夸大。
2. **同一个 DSH，八套皮肤：一个插件换掉整套品牌**
   最贴内容。适合当作系列第一篇的定调。
3. **拒绝花里胡哨：这个插件只做一件事，把 DSH 换成你喜欢的牌子**
   借鉴同赛道「拒绝废话」的句式，态度更硬。
4. **八张脸、二十种强调色，全部本地生效：DSH 换肤插件**
   信息量最大，但读起来像说明书，封面撑得住才用。
5. **装上它之后，我的 DSH 看起来像 Claude 官方版**
   第一人称，代入感强，缺点是没有数字。

首选 1，备选 2。标题不要带「最强」「神器」这类词，首条视频用会被当广告。

开源 MIT：
github.com/nonomint/multi-brand-theme

安装：插件页从本地目录装，装完完整重开一次 DSH。
设置 → 外观，三段各一个开关。

下一个做 SoC 拼图大亨，一个芯片设计的拼图游戏，做完了发这里。

三点说明，写简介时别丢：
1. 不放成本数字，按你之前定的，25.2 亿 Token 与 87.9 元只当幕后背景。
2. 不放「求三连」，首条视频强求转化会掉完播。
3. 结尾一句预告下一个项目，让来看插件的人知道这号还会发游戏。
